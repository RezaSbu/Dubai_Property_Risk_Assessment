# Dubai Property Risk Assessment 🏙️

Data-driven **risk assessment** for Dubai properties.

## Overview

In this project we generate random data for a set of property features, build a synthetic dataset, and analyze the **risk** factors that affect property outcomes in Dubai.

## What's Inside

- Synthetic dataset generation for property features
- Exploratory data analysis
- Statistical analysis of risk factors
- Jupyter Notebook based workflow

## Tech Stack

- Python
- Pandas / NumPy
- Jupyter Notebook

## Getting Started

```bash
jupyter notebook
```

Open the notebooks in order to follow the full analysis pipeline.
